# QR Reward full setup

Android app with login/register screens, server-sourced points, QR scanning, plus Node.js/SQLite backend.

Start with `backend/README.md` for server deployment and QR generation. Replace `https://YOUR_API_HOST/` in `app/build.gradle.kts` with the deployed HTTPS URL before building the APK. Do not distribute an APK with a placeholder API URL.

This ZIP is source code; it is not a compiled APK and the backend has not been deployed from this environment.
